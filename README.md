# car_play

Testi Spotify sincronizzati, a schermo intero, pensati per l'uso in auto.

L'app non riproduce audio: pilota il dispositivo attivo sulla sessione Spotify
Connect e ne mostra il testo riga per riga. Serve quindi che qualcosa sia gia'
in riproduzione su un altro dispositivo Spotify.

Setup, comandi e architettura sono in [CLAUDE.md](CLAUDE.md).

```bash
flutter pub get
flutter run -d <device>
```
